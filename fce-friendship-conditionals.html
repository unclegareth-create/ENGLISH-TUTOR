3. Remember Conditionals? Alternatives to "If"

Use of English Part 4

In B2 First, examiners test whether you can replace if with more precise conditional linkers:

Unless (= If ... not)

"You won't keep friends unless you make time for them."

As long as / Provided (that)

Means "only if / on condition that".
"I'll lend you my car as long as you fill the tank."

In case vs. If

Use in case for precautions done beforehand.
"Take a coat in case it rains later."

Otherwise / Or else

Means "because if not...".
"Apologise now; otherwise, she'll never forgive you."
