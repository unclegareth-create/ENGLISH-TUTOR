🕯️ While You’re Here: 30-Second Cambridge C1 Part 4 Challenge Formula: Negative Adverbial + Auxiliary + Subject + Bare Infinitive

1. I had no idea that this web page had been moved to another folder.

KEY WORD: LITTLE (Do not change this word • 3 to 6 words)

2. that this web page had been moved to another folder.

Cambridge Model (4 words): Little did I know (or Little did I realise)
Why it works: Echoes struck out: "that this web page had been moved...". Past simple in Sentence 1 ("had no idea") triggers inverted past auxiliary did + I + know.
