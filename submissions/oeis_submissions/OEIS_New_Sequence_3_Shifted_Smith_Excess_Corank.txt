%C AXXXXXX For the additively shifted GCD matrix G_n^(k) = [gcd(k+i, k+j)]_{1<=i,j<=n}, 2^(n-2) divides det(G_n^(k)) for all n >= 2 and all k >= 0. Whether v_2(det(G_n^(k))) can attain n - 2 is governed by the F_2-corank a(n) of the (n-2) X (n-2) quadratic form Q_n^(k) = B_n^T ((G_n^(k) - v_1 v_1^T - v_2 v_2^T)/2) B_n mod 2 on the parity-difference lattice B_n = span(e_i - e_{i-2} : 3 <= i <= n).
%C AXXXXXX For 2 <= n <= 13, a(n) = 0 (and min_{k>=0} v_2(det(G_n^(k))) = n - 2).
