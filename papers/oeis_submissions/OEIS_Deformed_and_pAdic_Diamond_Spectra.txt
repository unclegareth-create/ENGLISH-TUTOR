1. THEOREM A: THE DEFORMED ARITHMETIC DIAMOND PENCIL A_n^(r)(lambda)
========================================================================
Definition:
For any integer power r >= 1 and deformation parameter lambda in C, define the n X n Deformed Arithmetic Diamond Matrix pencil:
  A_n^(r)(lambda) = [ gcd(i, j)^r * (1 + lambda * delta_{v_2(i), v_2(j)}) ]_{1 <= i,j <= n},
where v_2(k) denotes the 2-adic valuation of k and delta_{a,b} is the Kronecker delta.

Specializations of the Pencil:
  * lambda = 0: H. J. S. Smith's power GCD matrix [gcd(i,j)^r] (1875), with determinant Product_{k=1..n} J_r(k).
  * lambda = 1: Power Arithmetic Diamond Matrix [gcd(i^r + j^r, |i^r - j^r|)].
  * lambda = -1: Hollow Dyadic GCD Matrix [gcd(i,j)^r * (1 - delta_{v_2(i), v_2(j)})], where entries sharing the same 2-adic valuation vanish.
  * lambda = -1/2: Half-Resonance GCD Matrix [gcd(i,j)^r * (1 - (1/2)*delta_{v_2(i), v_2(j)})], and (via reciprocal duality q -> 1/q) the Dual LCM Arithmetic Diamond Matrix L_n^(r) = [i^r * j^r / gcd(i^r + j^r, |i^r - j^r|)].
  * lambda = -2: Alternating Sign-Resonance Diamond Matrix [gcd(i,j)^r * (-1)^{delta_{v_2(i), v_2(j)}}], where entries with v_2(i) = v_2(j) flip sign.

Master Determinant Factorization (Theorem A):
For all n >= 1, r >= 1, and lambda in C:
  det A_n^(r)(lambda)
    = Product_{m=1..n, m odd} J_r(m)^(V_m + 1) * 2^(r * V_m * (V_m - 1) / 2) * Delta_{V_m}^(r)(lambda)
    = (Product_{k=1..n} J_r(k)) * Product_{m=1..n, m odd} ( Delta_{V_m}^(r)(lambda) / (2^r - 1)^(V_m) ),
where J_r(m) = m^r * Product_{p | m} (1 - p^(-r)) is Jordan's totient function, V_m = floor(log_2(n/m)), and
  Delta_V^(r)(lambda) = 2^(-r * V * (V - 1) / 2) * det[ 2^(r * min(a,b)) * (1 + lambda * delta_{a,b}) ]_{0 <= a,b <= V}.

Exact 3-Term Linear Recurrence & Universal Cassini Identity (with q = 2^r):
For all V >= 2:
  Delta_V^(r)(lambda) = ( (q + 1)*lambda + q - 1 ) * Delta_{V-1}^(r)(lambda) - q * lambda^2 * Delta_{V-2}^(r)(lambda),
with initial conditions:
  Delta_0^(r)(lambda) = 1 + lambda,
  Delta_1^(r)(lambda) = q * (1 + lambda)^2 - 1.
Ordinary Generating Function:
  Sum_{V >= 0} Delta_V^(r)(lambda) * x^V = ( 1 + lambda - (q - 1)*(lambda^2 - 1)*x ) / ( 1 - ((q + 1)*lambda + q - 1)*x + q * lambda^2 * x^2 ).
Universal Cassini Identity (independent of q - 1 cancellation!):
  (Delta_V^(r)(lambda))^2 - Delta_{V+1}^(r)(lambda) * Delta_{V-1}^(r)(lambda) = lambda^(2*V) * q^(V - 1)   for all V >= 1.

2. THEOREM B: UNIVERSAL p-ADIC VALUATION RESONANCE MATRIX A_{n,p}^(r)(lambda)
========================================================================
Definition:
For any prime p >= 2, integer power r >= 1, and deformation parameter lambda in C, define:
  A_{n,p}^(r)(lambda) = [ gcd(i, j)^r * (1 + lambda * delta_{v_p(i), v_p(j)}) ]_{1 <= i,j <= n}.

Master p-Adic Determinant Factorization (Theorem B):
Grouping {1, ..., n} by p-free part m (with p not dividing m) and p-adic valuation v_p(k) in {0, ..., V_{p,m}} where V_{p,m} = floor(log_p(n/m)), unit lower-triangular p-coprime Jordan totient congruence reduces A_{n,p}^(r)(lambda) to a direct sum of p-adic Kac-Murdock-Szego (KMS) Toeplitz blocks at coupling rho_{p,r} = p^(-r/2). With q = p^r:
  det A_{n,p}^(r)(lambda)
    = Product_{m=1..n, p \nmid m} J_r(m)^(V_{p,m} + 1) * p^(r * V_{p,m} * (V_{p,m} - 1) / 2) * Delta_{V_{p,m}}^(p,r)(lambda)
    = (Product_{k=1..n} J_r(k)) * Product_{m=1..n, p \nmid m} ( Delta_{V_{p,m}}^(p,r)(lambda) / (p^r - 1)^(V_{p,m}) ),
where Delta_V^(p,r)(lambda) = Delta_V(p^r, lambda) satisfies the exact same universal 3-term recurrence and Cassini identity with q = p^r:
  Delta_0^(p,r)(lambda) = 1 + lambda,
  Delta_1^(p,r)(lambda) = p^r * (1 + lambda)^2 - 1,
  Delta_V^(p,r)(lambda) = ( (p^r + 1)*lambda + p^r - 1 ) * Delta_{V-1}^(p,r)(lambda) - p^r * lambda^2 * Delta_{V-2}^(p,r)(lambda),
  (Delta_V^(p,r)(lambda))^2 - Delta_{V+1}^(p,r)(lambda) * Delta_{V-1}^(p,r)(lambda) = lambda^(2*V) * p^(r*(V - 1)).

Universal Pisot T-Sequence Theorem (lambda = 1, Arbitrary q = p^r >= 2):
At lambda = 1, Delta_0(q, 1) = 2, Delta_1(q, 1) = 4*q - 1, and Delta_V(q, 1) = (2*q)*Delta_{V-1}(q, 1) - q*Delta_{V-2}(q, 1).
By the universal Cassini identity, (Delta_V(q, 1))^2 - Delta_{V+1}(q, 1)*Delta_{V-1}(q, 1) = q^(V-1). Since 0 < q^(V-1) < Delta_{V-1}(q, 1) for all V >= 1 and q >= 2, we have:
  Delta_{V+1}(q, 1) = ceil( Delta_V(q, 1)^2 / Delta_{V-1}(q, 1) ) - 1,
proving that for EVERY prime power q = p^r >= 2, Delta_V^(p,r)(1) is the exact Pisot T-sequence T(2, 4*p^r - 1)!
Furthermore, in terms of Chebyshev polynomials of the second kind U_V(x):
  Delta_V(q, 1) = q^((V - 1)/2) * U_{V+1}( sqrt(q) ).

A. THE HOLLOW VALUATION-RESONANCE MATRIX (lambda = -1) & GAUSSIAN LUCAS SEQUENCES:
When lambda = -1, the diagonal of every KMS block vanishes: 1 + lambda*delta_{a,b} = 1 - delta_{a,b}.
The recurrence becomes:
  Delta_0(q, -1) = 0,   Delta_1(q, -1) = -1,   Delta_V(q, -1) = -2 * Delta_{V-1}(q, -1) - q * Delta_{V-2}(q, -1).
In exact closed form, this is the negative Lucas U-sequence U_V(-2, q) (or signed U_V(2, q) = Im((1 + i*sqrt(q-1))^V)/sqrt(q-1)):
  Delta_V(q, -1) = (-1)^V * Im( (1 + i * sqrt(q - 1))^V ) / sqrt(q - 1).
Global Singularity Theorem for Hollow Valuation-Resonance GCD Matrices:
  Because V_{p,m} = 0 whenever n/p < m <= n (with p \nmid m), and Delta_0(q, -1) = 0, the n X n Hollow p-adic GCD Matrix A_{n,p}^(r)(-1) has a 1 X 1 zero block [0] whenever there exists a p-coprime integer m in (n/p, n].
  * For p >= 3, m = n (if p \nmid n) or m = n - 1 (if p | n and n >= 2) always lies in (n/p, n], so det A_{n,p}^(r)(-1) = 0 for ALL n >= 1!
  * For p = 2, the interval (n/2, n] contains an odd integer for every n != 2. At n = 2, m = 1 is the unique odd integer <= 2 and V_{2,1} = 1, giving det A_2^(r)(-1) = -1. Thus det A_n^(r)(-1) = -delta_{n,2} for all n >= 1 and r >= 1!
