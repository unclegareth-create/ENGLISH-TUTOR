ABSTRACT
We prove a universal structural theorem that governs all multiplicative-valuation
arithmetic matrices on the truncated integer poset {1, 2, ..., n}. For ANY family
of 1D kernels {K_p(a, b)}_{a,b >= 0} indexed by the primes p <= n (which need not
even be symmetric or tridiagonal-invertible) satisfying the vacuum normalization
K_p(0, 0) = 1, the n X n arithmetic matrix

  M_n = [ prod_{p <= n} K_p(v_p(i), v_p(j)) ]_{1 <= i, j <= n}

admits an exact divisor-supported LU factorization (and Cholesky factorization
when each K_p is symmetric) directly on {1, 2, ..., n}. Because {1, 2, ..., n}
embeds via k |-> (v_p(k))_{p <= n} as a downward-closed order ideal in the
infinite direct-sum valuation poset bigoplus_{p} Z_{>= 0}, the tensor product of
the 1D lower/upper triangular factors L = bigotimes_p L^{(p)} and
U = bigotimes_p U^{(p)} is triangular with respect to divisibility (L_{i, d} = 0
and U_{d, j} = 0 unless d | i and d | j), so restriction to {1, 2, ..., n} is
exact with zero boundary leakage. Consequently, the determinant splits as a pure
product of 1D local leading principal minors:

  det(M_n) = prod_{k=1}^n prod_{p | k} d_p(v_p(k))
           = prod_{p <= n} prod_{\substack{1 <= u <= \lfloor n/p \rfloor \\ p \nmid u}}
               det(K_p[0 .. \lfloor \log_p(n/u) \rfloor]).

Specializing this Universal Poset Theorem to three fundamental arithmetic kernels
yields closed-form determinant laws and new OEIS connections:
  1. The 2-Parameter S-Adic Exponential-Decay & Valuation-Resonance Diamond Matrix
     and the Deformed GCD-to-LCM Power Matrix (with effective KMS base Q_p = p^{r+s}).
  2. The Unitary GCD Arithmetic Diamond Matrix via the Matrix Determinant Lemma
     (generalizing OEIS A321613).
  3. The Divisor-Count (tau) / Linear Valuation Arithmetic Diamond Matrix, whose
     local block polynomial W_V(x, lambda) is the infinitesimal q -> 1 limit of
     the KMS polynomial Delta_V(q, lambda) and evaluates at (x=1, lambda=1) to
     the odd-indexed Fibonacci numbers F_{2V+3} (OEIS A001519).

1. THEOREM I: UNIVERSAL MULTIPLICATIVE-VALUATION POSET LU/CHOLESKY THEOREM
--------------------------------------------------------------------------------
Let {K_p(a, b)}_{a,b >= 0} be an arbitrary family of 1D matrices indexed by the
primes p, with K_p(0, 0) = 1, such that for each p the leading principal minors
Delta_V^{(p)} := det(K_p[0 .. V]) are non-zero. Let

  K_p = L^{(p)} D^{(p)} U^{(p)}

be the unique unit-triangular LU decomposition of K_p on Z_{>= 0}, where
L^{(p)}_{a, c} = 0 for c > a, U^{(p)}_{c, b} = 0 for c > b, L^{(p)}_{a, a} =
U^{(p)}_{a, a} = 1, and D^{(p)} = diag(d_p(0), d_p(1), ...), with d_p(0) = 1 and

  d_p(a) = Delta_a^{(p)} / Delta_{a-1}^{(p)}   (a >= 1).

Define the arithmetic matrix M_n on {1, 2, ..., n} by

  (M_n)_{i, j} = prod_{p <= n} K_p(v_p(i), v_p(j))   (1 <= i, j <= n).

THEOREM I (Universal Poset Factorization & Determinant Product Law):
(a) Define the n X n matrices L, D, U on {1, 2, ..., n} by:
      L_{i, m} = prod_{p <= n} L^{(p)}_{v_p(i), v_p(m)}   if m | i, and 0 otherwise;
      U_{m, j} = prod_{p <= n} U^{(p)}_{v_p(m), v_p(j)}   if m | j, and 0 otherwise;
      D = diag(D_1, D_2, ..., D_n),   where D_m = prod_{p | m} d_p(v_p(m)).
    Then L is unit lower-triangular, U is unit upper-triangular, and on {1, ..., n}:

      M_n = L D U.

(b) In particular, the determinant of M_n factors into a product of 1D leading
    principal minors across the p-coprime chain roots u:

      det(M_n) = prod_{m=1}^n prod_{p | m} d_p(v_p(m))
               = prod_{p <= n} prod_{\substack{1 <= u <= \lfloor n/p \rfloor \\ p \nmid u}}
                   det(K_p[0 .. \lfloor \log_p(n/u) \rfloor]).

(c) The inverse M_n^{-1} on {1, 2, ..., n} is given explicitly by the Mobius-poset
    Green's sum over common multiples m of i and j inside {1, 2, ..., n}:

      (M_n^{-1})_{i, j} = sum_{\substack{1 <= m <= n \\ \operatorname{lcm}(i, j) | m}}
                            \frac{(U^{-1})_{i, m} (L^{-1})_{m, j}}{D_m}.

PROOF:
For any 1 <= i, j <= n and each prime p <= n, the 1D LU factorization gives
  K_p(v_p(i), v_p(j)) = sum_{c_p = 0}^{\min(v_p(i), v_p(j))}
                          L^{(p)}_{v_p(i), c_p} d_p(c_p) U^{(p)}_{c_p, v_p(j)}.
Taking the product over all p <= n and expanding multi-linearly over tuples
(c_p)_{p <= n} satisfying 0 <= c_p <= min(v_p(i), v_p(j)), the bijection
m = prod_{p <= n} p^{c_p} maps the index set {0 <= c_p <= min(v_p(i), v_p(j))}
bijectively onto the set of common divisors {m >= 1 : m | gcd(i, j)}.
Because {1, 2, ..., n} is downward-closed under divisibility, every divisor
m | gcd(i, j) satisfies m <= min(i, j) <= n, so every intermediate state m in the
tensor-product LU sum lies strictly inside {1, 2, ..., n}! Since d_p(0) =
L^{(p)}_{0, 0} = U^{(p)}_{0, 0} = 1, the product over p <= n equals L_{i, m} D_m U_{m, j},
proving M_n = L D U on {1, ..., n}. Partitioning {1, ..., n} into p-adic chains
m = u * p^a (p \nmid u, 0 <= a <= V_{p, u} := \lfloor \log_p(n/u) \rfloor) telescopes
prod_{a=0}^{V_{p, u}} d_p(a) = det(K_p[0 .. V_{p, u}]), yielding (b). Q.E.D.

2. THEOREM II: THE 2-PARAMETER S-ADIC EXPONENTIAL-DECAY & GCD-TO-LCM DIAMONDS
--------------------------------------------------------------------------------
Let S be any set of primes, and for each p in S let rho_p, lambda_p be parameters.
Define the 2-Parameter S-Adic Exponential-Decay & Valuation-Resonance Diamond Matrix:

  M_{n, S}^{(r)}(\boldsymbol{\rho}, \boldsymbol{\lambda})_{i, j}
    = gcd(i, j)^r * prod_{p \in S} (rho_p^{|v_p(i) - v_p(j)|} + lambda_p * delta_{v_p(i), v_p(j)}).

THEOREM II (Gauge-Rescaled KMS Law & Effective Base Q_p = p^{r+s}):
(a) Observe the exact 1D gauge-rescaling identity for any q_p, rho_p, lambda_p:
      q_p^{\min(a, b)} (rho_p^{|a - b|} + lambda_p * delta_{a, b})
        = rho_p^a * rho_p^b * [ (q_p / rho_p^2)^{\min(a, b)} (1 + lambda_p * delta_{a, b}) ].
    Consequently, the (V+1) X (V+1) local block determinant is governed by the
    effective KMS base Q_p := q_p / rho_p^2:

      det[ q_p^{\min(a, b)} (rho_p^{|a - b|} + lambda_p * delta_{a, b}) ]_{0 <= a, b <= V}
        = rho_p^{2 V} * q_p^{V(V-1)/2} * Delta_V(q_p / rho_p^2, lambda_p).

(b) Applying Theorem I with q_p = p^r gives the exact global determinant on {1, ..., n}:
      det M_{n, S}^{(r)}(\boldsymbol{\rho}, \boldsymbol{\lambda})
        = (prod_{k=1}^n J_r(k)) * prod_{p \in S} [ (1 + lambda_p)^{e_{p, 0}(n)}
            * prod_{\substack{1 <= u <= \lfloor n/p \rfloor \\ p \nmid u}}
                (\frac{rho_p^2}{p^r - 1})^{V_{p, u}} Delta_{V_{p, u}}(p^r / rho_p^2, lambda_p) ].

(c) Corollary (Deformed GCD-to-LCM Power Matrix):
    Since gcd(i, j)^r / lcm(i, j)^s = prod_p p^{(r-s)\min(v_p(i), v_p(j)) - s|v_p(i) - v_p(j)|},
    setting q_p = p^{r-s} and rho_p = p^{-s} yields the effective KMS base
      Q_p = q_p / rho_p^2 = p^{r-s} / p^{-2s} = p^{r+s}.
    Therefore, the normalized Deformed GCD-to-LCM Power Matrix
      G_n^{(r, s)}(\boldsymbol{\lambda})_{i, j}
        = \frac{\gcd(i, j)^r}{\operatorname{lcm}(i, j)^s}
          * prod_{p <= n} \frac{1 + \lambda_p p^{s|v_p(i) - v_p(j)|} \delta_{v_p(i), v_p(j)}}{1 + \lambda_p}
    has exact determinant:
      det G_n^{(r, s)}(\boldsymbol{\lambda})
        = prod_{p <= n} prod_{\substack{1 <= u <= \lfloor n/p \rfloor \\ p \nmid u}}
            \frac{p^{-2 s V_{p, u} + (r-s) V_{p, u}(V_{p, u}-1)/2} \Delta_{V_{p, u}}(p^{r+s}, \lambda_p)}{(1 + \lambda_p)^{V_{p, u} + 1}}.

3. THEOREM III: UNITARY GCD ARITHMETIC DIAMOND MATRIX (OEIS A321613)
--------------------------------------------------------------------------------
Recall that d is a unitary divisor of n (written d || n) if d | n and gcd(d, n/d) = 1.
The unitary greatest common divisor is
  gcd*(i, j)^r = prod_{\substack{p <= n \\ v_p(i) = v_p(j) >= 1}} p^{r v_p(i)}.
Its local 1D valuation kernel with resonance deformation lambda_p is the rank-1
perturbation of a diagonal matrix:
  K_p^*(a, b; \lambda_p) = \frac{1 + (p^{r a}(1 + \lambda_p) - 1) \delta_{a, b}}{1 + \lambda_p}.

THEOREM III (Unitary GCD Diamond Determinant via Matrix Determinant Lemma):
Set D_a^{(p)} := p^{r a}(1 + \lambda_p) - 1 for a >= 0. By the Matrix Determinant
Lemma applied to 1 * 1^T + diag(D_0^{(p)}, ..., D_V^{(p)}), the (V+1) X (V+1)
local block determinant is:
  det K_p^*[0 .. V] = \frac{\prod_{a=0}^V D_a^{(p)} + \sum_{a=0}^V \prod_{b \neq a} D_b^{(p)}}{(1 + \lambda_p)^{V+1}}.
At lambda_p = 0, D_0^{(p)} = 0 and D_a^{(p)} = p^{r a} - 1 (a >= 1), so only the
a = 0 term in the sum survives:
  det K_p^*[0 .. V]|_{\lambda_p = 0} = prod_{a=1}^V (p^{r a} - 1),
and Theorem I immediately gives the closed-form determinant of the Unitary GCD
Matrix [gcd*(i, j)^r]_{1 <= i, j <= n}:
  det[gcd*(i, j)^r]_{1 <= i, j <= n} = prod_{k=1}^n prod_{p | k} (p^{r v_p(k)} - 1)
(recovering OEIS A321613 at r = 1: 1, 1, 2, 6, 24, 48, 288, 2016, 16128, 129024, ...).

4. THEOREM IV: DIVISOR-COUNT (TAU) DIAMOND MATRIX & FIBONACCI BISECTION LAW
--------------------------------------------------------------------------------
Since the divisor-count function tau(m) = sum_{d | m} 1 satisfies
  tau(gcd(i, j)) = prod_p (1 + \min(v_p(i), v_p(j))),
consider the 2-parameter Linear-Valuation (Brownian/Wiener) Diamond Matrix:
  T_n(x, \lambda)_{i, j} = prod_{p <= n} \frac{1 + x \min(v_p(i), v_p(j)) + \lambda \delta_{v_p(i), v_p(j)}}{1 + \lambda}.

THEOREM IV (Infinitesimal KMS Limit & Odd-Indexed Fibonacci Determinants):
(a) Let W_V(x, \lambda) := det[1 + x \min(a, b) + \lambda \delta_{a, b}]_{0 <= a, b <= V}.
    Since (1 + \epsilon x)^{\min(a, b)} = 1 + \epsilon x \min(a, b) + O(\epsilon^2),
    W_V(x, \lambda) is the exact q -> 1 scaling limit of the KMS polynomial:
      W_V(x, \lambda) = \lim_{\epsilon \to 0} \epsilon^{-V} \Delta_V(1 + \epsilon x, \epsilon \lambda).

(b) W_V(x, \lambda) satisfies the constant-coefficient second-order recurrence:
      W_0(x, \lambda) = 1 + \lambda,
      W_1(x, \lambda) = \lambda^2 + (x + 2)\lambda + x,
      W_V(x, \lambda) = (x + 2\lambda) W_{V-1}(x, \lambda) - \lambda^2 W_{V-2}(x, \lambda)   (V >= 2),
    and the universal Cassini identity for all V >= 1:
      W_V(x, \lambda)^2 - W_{V+1}(x, \lambda) W_{V-1}(x, \lambda) = (1 - x(1 + \lambda)) \lambda^{2 V}.

(c) Exact OEIS Evaluations of W_V(x, \lambda):
    - At (x = 1, \lambda = 1): The recurrence is W_V = 3 W_{V-1} - W_{V-2} with
      W_0 = 2 = F_3, W_1 = 5 = F_5, W_2 = 13 = F_7, W_3 = 34 = F_9, ...
      Hence for all V >= 0:
        W_V(1, 1) = F_{2V + 3}   (Odd-indexed Fibonacci numbers, OEIS A001519)!
      And by Theorem I, the determinant of the Divisor-Count Diamond Matrix at (x=1, \lambda=1) is a
      pure product of odd-indexed Fibonacci numbers across the prime valuation towers:
        det T_n(1, 1) = prod_{p <= n} prod_{\substack{1 <= u <= \lfloor n/p \rfloor \\ p \nmid u}}
                          \frac{F_{2 V_{p, u} + 3}}{2^{V_{p, u} + 1}}.
    - At (x = 1, \lambda = 2): W_V(1, 2) = 3, 11, 43, 171, 683, 2731, ...
      = (2^{2V+3} + 1) / 3 (OEIS A007583).
    - At (x = 1, \lambda = -1): W_V(1, -1) = (-1)^{V(V+1)/2} (0, 1, -1, -1, 1, 1, ...),
      giving a unimodular (+/- 1) determinant for every n >= 2 where V_{p, u} >= 1.
