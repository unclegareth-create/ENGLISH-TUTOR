1. The 4 Advanced Conditional Formulas

Formulas & Rules

Basic conditionals link past to past or present to present. C1/C2 counterfactuals cross time boundaries or drop 'if' entirely:

1. Past Action → Present Result (Mixed Type A)

A past choice caused your present situation:

If + had V3, Subject + would/could + V1 (now)

"If I had taken that job, I would live in London now."

2. Ongoing Trait → Past Result (Mixed Type B)

A permanent trait prevented a past event:

If + Past Simple / Were, Subject + would have + V3

"If she weren't so confident, she wouldn't have applied."

3. Conditional Inversion (Eliminating 'IF')

Formal academic register for policy and essays:

Had / Were / Should + Subject + Verb

"Had the council acted sooner, floods would not occur."

4. Strict Alternatives to IF

Precise prerequisite or negative condition:

Provided that (only if) • But for + Noun (had it not been for)

"But for timely funding, the laboratory would have closed."

2. Structural Precision: Standard vs C1 Inverted

Exam Register
Conditional Type Standard B2 Form High-Scoring C1/C2 Inversion
Type 1 (Unlikely Event) If you need any assistance... Should you require any assistance...
Type 2 (Hypothetical Policy) If the government banned cars... Were the government to ban cars...
Type 3 (Past Counterfactual) If planners had foreseen the risk... Had planners foreseen the risk...
Negative Counterfactual If it hadn't been for the grant... But for the research grant...

Apply Gareth's 4-Step Elimination & Deconstruction Strategy: (1) Strike out echoes to isolate the semantic deficit, (2) Inspect tense harmony, (3) Check voice shift, and (4) Fit the 3–6 word gap with the unchanged keyword.

4-Step Deconstruction
LOCK 1 • 4,000m (ABYSSAL MARGIN) If you should notice any hull micro-fractures, abort the dive immediately.
HAPPEN KEYWORD: HAPPEN (MISSING) 0 WORDS (3–6 REQ)
Step 2 Tense Harmony: Modal Present (should notice) → Bare Infinitive after Inverted Should Step 3 Voice Shift: Active → Active (Should + Subject + happen to V1)
Should hull micro-fractures, abort the dive immediately.
Cambridge Model: you happen (1 mark) // to notice (any) (1 mark)
4-Step Check: Inverted Type 1 conditional Should + subject + happen + to-infinitive expresses remote possibility in formal briefings.
LOCK 2 • 5,500m (ABYSSAL PLAIN) If the crew had not reacted so swiftly, the submersible would have lost buoyancy.
BEEN KEYWORD: BEEN (MISSING) 0 WORDS (3–6 REQ)
Step 2 Tense Harmony: Past Perfect (had not reacted) → Inverted Past Perfect (Had it not been) Step 3 Voice Shift: Verb + Adverb (reacted swiftly) → Adjective + Noun (swift reaction)
Had reaction of the crew, the submersible would have lost buoyancy.
Cambridge Model: it not been (1 mark) // for the swift (1 mark)
4-Step Check: Had it not been for + noun phrase is the fixed C1/C2 inverted counterfactual frame.
LOCK 3 • 7,000m (HADAL GATE) The expedition will proceed only if the acoustic beacons function flawlessly.
CONDITION KEYWORD: CONDITION (MISSING) 0 WORDS (3–6 REQ)
Step 2 Tense Harmony: Future + Present Simple (will proceed / function) Step 3 Voice Shift: Active → Active Prerequisite Conjunction
The expedition will proceed the acoustic beacons function flawlessly.
Cambridge Model: (only) on condition (1 mark) // that (1 mark)
4-Step Check: only if maps directly to the zero-article C1 prepositional conjunction on condition that.
LOCK 4 • 8,500m (MARIANA RIDGE) Without the pilot's calm judgement, the deep-sea mission would have failed last night.
WERE KEYWORD: WERE (MISSING) 0 WORDS (3–6 REQ)
Step 2 Tense Harmony: Mixed Type B (Present Ongoing Trait → Past Result would have failed) Step 3 Voice Shift: Preposition (Without) → Subjunctive Inversion (Were it not for)
the pilot's calm judgement, the deep-sea mission would have failed last night.
Cambridge Model: Were it (1 mark) // not for (1 mark)
4-Step Check: Because the pilot's calm judgement is a permanent trait, Were it not for pairs with the past result would have failed.
LOCK 5 • 9,800m (SIRENA DEEP) The marine biologists regret not deploying the thermal sensors before the current shifted.
WISH KEYWORD: WISH (MISSING) 0 WORDS (3–6 REQ)
Step 2 Tense Harmony: Present Regret of Past Action → wish + Past Perfect (had deployed) Step 3 Voice Shift: Negative Gerund (not deploying) → Affirmative Past Perfect Clause
The marine biologists the thermal sensors before the current shifted.
Cambridge Model: wish (that) they (1 mark) // had deployed (1 mark)
4-Step Check: Polarity flips from negative (regret not deploying) to affirmative counterfactual (wish they had deployed).
LOCK 6 • 10,900m (CHALLENGER DEEP) The technician recalibrated the oxygen valves in time; if he hadn't, the dive would have been scrubbed.
OTHERWISE KEYWORD: OTHERWISE (MISSING) 0 WORDS (3–6 REQ)
Step 2 Tense Harmony: Past Fact (recalibrated) + Past Modal Result (would have been scrubbed) Step 3 Voice Shift: Active Condition (if he hadn't) → Adverbial Connector (otherwise) + Passive Subject
The technician recalibrated the oxygen valves in time; have been scrubbed.
Cambridge Model: otherwise (1 mark) // the dive would (1 mark)
4-Step Check: Otherwise absorbs the entire negative condition if he hadn't.
